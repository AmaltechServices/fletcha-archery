# Fletcha Archery — V10 Social Video

Approved full-width hero image preserved unchanged. Adds six official TikTok embeds, TikTok profile link, Facebook and Instagram links in news, contact, and footer. Uses the ten real club photos from V9.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Build: `npm run build`; Publish directory: `dist`.

TikTok video availability, third-party cookies, and iframe embedding restrictions are controlled by TikTok and browsers. Each embed has a direct link fallback. Videos are not copied or hosted locally. Obtain consent before publicly publishing photos of members, especially minors.
